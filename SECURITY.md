# Security Policy

## Supported versions

Only the latest published release of FTMS Bike Bridge receives security fixes. Please update to the [latest release](https://github.com/Mahagon/ftsm-indoorbike-googlefit-bridge/releases/latest) before reporting an issue that may already be resolved.

## Reporting a vulnerability

Please do not disclose an unpatched vulnerability in a public issue, discussion, or pull request. Use GitHub's **Security → Report a vulnerability** form to submit a private vulnerability report.

Include as much of the following as possible:

- The affected app version and Android version.
- A description of the impact and affected functionality.
- Reproduction steps or a minimal proof of concept.
- Relevant logs with credentials, personal data, and device identifiers removed.
- Any suggested mitigation or remediation.

You should receive an acknowledgement within three business days. We will investigate, keep you informed of material progress, and coordinate disclosure after a fix is available. Please allow a reasonable remediation period before publishing details.

Good-faith research that avoids privacy violations, data destruction, service disruption, and access beyond what is necessary to demonstrate the issue is welcome.
